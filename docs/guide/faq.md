# 7. 자주 묻는 질문 · 문제 해결

[← 사용 가이드 목차](../../README.md#사용-가이드)

### 내 문서가 어딘가로 올라가나요?

아니요. JayDocs 에는 서버가 없어요. 코드는 브라우저 안에서 돌고, 내 PC 의 폴더를 직접 읽고 써요. 인터넷이 끊겨도 돌아가요(처음 한 번만 인터넷이 필요해요).

### 열 때마다 "허용" 을 눌러야 해요.

브라우저 탭으로 쓰면 창을 닫을 때 폴더 권한이 풀릴 수 있어요. **앱으로 설치**해서 쓰면 권한이 유지돼요. ([시작하기](getting-started.md))

### Firefox · Safari · 휴대폰에서는요?

폴더를 직접 여는 기능(File System Access)이 Edge · Chrome 에만 있어서 안 돼요. Chrome 은 되지만, 파일 이름 바꾸기를 "복사 후 삭제" 로 처리해요. **Edge 를 권해요.**

### 폴더 이름은 어떻게 바꿔요?

브라우저에 폴더를 옮기는 기능이 없어서, 폴더 이름은 Windows 탐색기에서 바꿔 주세요. 트리는 저절로 따라와요. 파일 이름은 JayDocs 에서 바꿀 수 있어요(오른쪽 클릭 → 이름 바꾸기, 또는 `F2`).

### 파일을 실수로 지웠어요.

앱에서 지운 파일은 **휴지통으로 가지 않아요.** git 으로 관리하는 폴더라면 GitHub Desktop 등에서 되돌릴 수 있어요. 그래서 처음엔 복사본이나 git 폴더로 써 보시길 권해요.

### 파일이 🔒 읽기 전용으로 열려요.

- **한글이 옛 인코딩(CP949/EUC-KR)인 파일**이에요. 메모장 "ANSI" 나 한글 엑셀의 "CSV(쉼표로 분리)" 로 저장한 파일이 그래요. 그대로 저장하면 한글이 깨질 수 있어서 막아 둔 거예요. 위 배너의 **UTF-8 로 바꿔 저장** 을 누르면 그 뒤로는 평소처럼 고칠 수 있어요.
- **읽기 전용으로 가져온 폴더**의 파일일 수도 있어요. 트리의 `@별칭` 오른쪽 클릭 → 읽기 전용 끄기.

### 파일이 안 열려요.

5 MB 넘는 파일, UTF-16 파일, 이름만 txt 인 바이너리 파일은 열지 않고 이유를 보여 줘요.

### 저장이 안 돼요.

엑셀 같은 다른 프로그램이 그 파일을 열어 잠그고 있으면 저장이 막혀요(원본은 그대로예요). 엑셀을 닫고 다시 저장해 주세요.

### 엑셀에서 열면 "제한된 보기" 로 열려요.

브라우저가 저장한 파일에 "인터넷에서 받은 파일" 표시를 붙이기 때문이에요. 내용과 git 에는 영향이 없어요. 문서 폴더를 엑셀의 **신뢰할 수 있는 위치**에 넣으면 사라져요.

### git diff 가 너무 크게 나와요.

JayDocs 는 고친 행만 다시 써요. 다만 **열을 넣거나 빼거나 옮기면** 모든 줄이 바뀌어요(묻지는 않고, 오른쪽 아래 알림으로 알려 주며 **되돌리기** 나 `Ctrl+Z` 로 되돌려요). JSON **정렬** 버튼도 파일 전체를 다시 써요.

### 새 버전이 안 보여요.

새 버전은 **모든 JayDocs 창을 닫고 다시 열 때** 적용돼요. 바로 받고 싶으면 **업데이트 확인** → **새 버전 적용**. ([업데이트](workspace.md#업데이트))
