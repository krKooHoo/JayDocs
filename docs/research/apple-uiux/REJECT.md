# JayDocs 업데이트 — 가져오지 않을 것

2026-11-22. `PRINCIPLES.md` 의 일곱 원칙과 Apple 도구 조사(01~09, 종합 `README.md`)를 바탕으로, 가져오지 않을 것과 그 이유를 적는다. 가져올 것은 [ADOPT.md](ADOPT.md).

네 갈래로 나눈다.

1. **원칙에 어긋나서** 가져오지 않는 것
2. 원칙에는 맞지만 **이득이 작아서** 하지 않는 것
3. **보류** — 조건이 되면 다시 본다
4. Apple 관행과 다르지만 **지금 방식을 유지**하는 것

괄호의 번호는 근거가 된 조사 리포트다. 같은 요청이 다시 오면 이 표로 먼저 크로스 체크한다.

## 4. Apple 관행과 다르지만 지금 방식을 유지하는 것

| JayDocs 지금 | Apple 관행 | 유지하는 이유 |
|---|---|---|
| 되돌릴 수 없는 확인창은 처음 포커스가 **취소** | HIG: 취소를 기본 버튼으로 하지 않는다 | 웹 대화상자에서 `Enter` 를 이어 눌러 지우는 사고를 막는 쪽이 낫다 |
| 앱 안 다크 / 라이트 전환(`Ctrl+Alt+D`) | HIG: 앱 전용 모양 설정을 두지 않는다 | 시작은 OS 설정을 따른다. Windows PWA 에서는 앱 안 전환이 흔한 관행이다 |
